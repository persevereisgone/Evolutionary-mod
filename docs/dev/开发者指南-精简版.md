### 6.1 命令速查（游戏内输入，需 OP 权限等级 2）

- `/acc help`
  - 注释：显示命令总览与用法提示。
  - 适用：忘记子命令或参数格式时。

- `/acc stats`
  - 注释：输出基础统计（系统状态、strict 模式状态、常用提示）。
  - 适用：快速确认当前模组运行状态。

- `/acc stats detail`
  - 注释：输出详细统计（词条/掉落的已加载数、无效条目数、回退命中数）。
  - 适用：调参后做一次“全局健康检查”。

- `/acc validate`
  - 注释：输出数据配置校验报告，重点看无效条目与回退命中是否大于 0。
  - 适用：发布前、联机前、自测收尾阶段。

- `/acc drop query <loot_table_id>`
  - 注释：查询某个掉落表当前生效配置，显示来源（JSON 或 Java 回退）、掉率和品阶集合。
  - 示例：`/acc drop query minecraft:entities/zombie`

- `/acc attr query <item_id>`
  - 注释：查询某个物品是否命中词条 JSON 配置（未命中则会走回退逻辑）。
  - 示例：`/acc attr query evolutionary_mod:life_essence_ring`

- `/acc set query <set_type>`
  - 注释：按套装类型查询当前生效参数（当前可用：`dragon`）。
  - 示例：`/acc set query dragon`
  - 适用：验证 `dragon_set.json` 是否按预期生效，并为后续多套装扩展预留统一入口。

- `/acc equipped`
  - 注释：查看玩家当前已装备饰品（按槽位输出）。
  - 适用：联调装备同步、槽位绑定与显示问题。

- `/acc export csv`
  - 注释：导出掉率报表到 `accessories_export/accessory_drop_rates.csv`。
  - 适用：做平衡对比、版本前后掉率复核。

## 8) Patchouli 引导书
- 书 ID：`evolutionary_mod:guide`
- 获取：创造标签「饰品」；合成 `书 + 金粒`；指令 `/give @s patchouli:guide_book[patchouli:book="evolutionary_mod:guide"]`
- 正文与分类标题走 lang（`i18n: true`），改文案优先改 `zh_cn.json` / `en_us.json`
- 依赖：`Patchouli 1.21.1-93-NEOFORGE`（见 `gradle.properties` 的 `patchouli_version`）
- **完整维护说明**：`docs/dev/Patchouli引导书开发指南.md`（目录结构、现有条目清单、增改步骤、热重载与坑）

## 10) Blockbench 建模与提示词生成（3D 资源）

- **规则**：`.cursor/rules/blockbench-modeling.mdc`（凡是生成 Blockbench 建模提示词 / 用 MCP 驱动建模，必读）
- **详细规范与模板**：`docs/dev/Blockbench建模与提示词规范.md`（提示词模板、硬检查清单、禁止项）
- **skill 库**：`block_bench_skills/`（`blockbench-use` 必读；modeling / texturing / animation / pbr-materials / hytale 按需加载）
- **提示词生成流程**：先读规则 → 明确类型/用途/结构/材质/颜色/动画/禁止项 → 过硬检查清单 → 再交付
- **MCP 建模流程**：`blockbench-use` 前置检查 → 建骨骼分组 → `save_checkpoint` → 建模/贴图/动画 → `capture_screenshot` → 按需导出
- **材料类物品**：16×16 透明底、单体居中、系列内颜色/剪影不撞车（联动 `texture-processing.mdc`）
- **Boss/实体**：轮廓优先、分组清晰、发光核心明确、禁止过碎细节；若为模组实体须联动 §4 实体注册链路
