====================================================
 武器图片 AI 提示词【中文版】（武器系统 v1.0）
 覆盖：11 把武器 = 近战 4 + 远程 1 + 法术 4 + 辅助 1 + 爪类 1
 适用：即梦 / 可灵 / 通义万相 等中文生图工具
====================================================

【系列设计思路】
- 11 把武器 = 11 种独立剪影，造型互不雷同：
  * 逐日之刃 —— 直刃长剑
  * 裂地战斧 —— 宽刃战斧
  * 影袭匕首 —— 弯月匕首
  * 穿云长枪 —— 长柄刺枪
  * 霜语法杖 —— 雪花法杖
  * 圣辉权杖 —— 日轮权杖
  * 噬魂镰刀 —— 收割长镰
  * 雷鸣战锤 —— 六边巨锤
  * 龙牙利爪 —— 扇形三刃爪
  * 元素魔典 —— 摊开魔典
  * 猎风长弓 —— 反曲长弓
- 颜色铺满整个色环；11 把武器主色两两拉开：
  熔金橙红 → 岩褐深棕 → 暗紫幽黑 → 银白天青 → 冰蓝月白 → 鎏金珍珠白 →
  幽绿墨黑 → 靛蓝闪电黄 → 龙血红金 → 深紫三色 → 苍绿藤棕。
- 每把武器的纹饰 / 徽记 / 特效都对应它的两个技能
  （技能名已写进描述里，方便生图时对照检查）。
- 统一语言只保留四点：全部居中构图、全部透明背景、
  全部体素方块像素风格、全部无文字。
- 武器是独立静物，不要人物 / 手 / 生物握着或拿着。
- 成图规格：512x512 即可，之后缩到 Minecraft 16x16；
  背景必须完全透明（游戏贴图不能有底色/底板）、物品居中、无文字。

 四、使用建议
====================================================
1. 所有图标统一使用「完全透明背景」生成，严禁出现任何底色/底板，
   否则进游戏后物品框会被黑底遮挡，拿在手上也是黑色方块。
   若生图工具不支持透明 PNG，请生成后在图片处理软件中一键抠掉纯色背景。
2. 缩到 16x16 后若轮廓看不清，优先保持「颜色 + 剪影」，不要强塞细节，
   靠不同的外形剪影区分（这正是 11 把武器独立造型的意义）。
3. 生成文件命名直接对齐游戏内物品注册名（建议 .png）：
   sun_blade / earth_split_axe / shadow_strike_dagger / cloud_pierce_spear /
   frost_art_staff / holy_glory_scepter / soul_harvest_scythe /
   thunder_war_hammer / dragon_fang_claw / elemental_grimoire / wind_hunter_bow
   存放路径：src/main/resources/assets/evolutionary_mod/textures/item/
4. 11 把武器建议「一整组一起生成」并检查颜色两两可辨，
   近战四件（剑/斧/匕首/长枪）剪影差异最大、最容易一起出图；
   法术四件（法杖/权杖/魔典）建议拆开单独生成，避免书本和法杖混淆。
5. 生图后重点检查：武器是否被画歪、是否出现握武器的手、
   背景是否带天空/云层/光柱（都会在 16x16 下糊成一团），
   有问题的直接重画，不要在图片软件里强行修补。
6. 中文提示词针对即梦 / 可灵 / 通义万相等国内工具优化；
   若用 Midjourney 或 Stable Diffusion，请用英文版提示词并保留同样的结构。
