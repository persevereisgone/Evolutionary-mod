# 任务系统 GUI 设计文档（三栏面板 · 亮色调度台）

> 本文件为可直接投喂给 AI 进行 GUI 设计的完整需求文档。
> 适用项目：Evolutionary Mod（Minecraft 1.21.1 / NeoForge）
> 设计对象：`evolutionary_mod` 任务系统交互界面
> 参照设计稿：任务系统 UI 设计图（网页三栏布局截图）
> 对应代码骨架：`client/TaskScreen.java`（示例实现，坐标与本文档一致）

---

## 一、文档目的

基于一张「三栏式」任务系统 UI 设计图，产出一套**布局格式不变、内容可完全替换**的 Minecraft GUI 方案。

设计稿中包含了大量具体文字（账号信息、时间、统计数字等），**不能直接作为背景贴图使用**。本方案的核心原则是：

> **骨架与内容分离** —— 骨架（面板、边框、按钮、页签、分区）进贴图或代码绘制；**所有文字、数字、物品图标、进度**一律由游戏内字体/渲染器动态绘制，永不进贴图。

产出物要求：
1. 一套完整 GUI 贴图设计（空白骨架，不含任何文字）。
2. 每一部分附可直接生成图片的英文 Prompt。
3. 布局必须符合下述硬性约束，保证实装时可直接切割为游戏贴图、并与代码坐标一一对应。

---

## 二、系统背景（AI 需要知道的语境）

这是 Minecraft 模组的任务系统，玩家通过快捷键呼出任务面板，浏览与操作任务：

| 元素 | 说明 |
|------|------|
| 任务分类 | 主线 / 支线 / 日常 / 活动（+「全部」汇总页签） |
| 任务状态 | 未接取（灰）/ 进行中（蓝）/ 已完成（绿） |
| 任务操作 | 接取、追踪（地图/UI 高亮目标）、放弃 |
| 任务内容 | 名称、进度 x/y、奖励（经验/物品） |
| 附加信息 | 完成度进度条、任务日志、在线状态、开关（自动追踪/新任务提醒） |
| 辅助区域 | 任务筛选、可接取推荐、世界动态 |

**设计基调**：这是一块"游戏内任务面板"，应具备原版 Minecraft 容器界面的观感——斜切描边灰板、blocky 像素块状质感；整体用深蓝 `#1E3A5F` + 金色 `#FFD700` 在最外框做点缀，突出"任务/委托"的正式感。简单、硬朗、像游戏原生 UI。

## 三、设计总纲

### 3.1 风格定位

- **一句话**：Minecraft 原版容器 GUI 质感（斜切描边灰板）+ 深蓝外框蓝金点缀。
- **氛围**：像游戏内自带的一块"任务面板"，与背包/工作台界面观感一致。
- **情绪**：硬朗、块状、像素感，简单不花哨。

### 3.2 配色方案（全系统统一，禁止外溢）

| 用途 | 色值 | 说明 |
|------|------|------|
| 面板主体（MC 灰） | `#8B8B8B` | 斜切描边内填充 |
| 面板高光（左上） | `#C6C6C6` | 1px 亮边 |
| 面板阴影（右下） | `#555555` | 1px 暗边 |
| 面板内衬（更深） | `#6B6B6B` | 列表/日志底 |
| 顶栏 / 内凹底槽 | `#3C3C3C` | 深灰黑 |
| 外框深蓝 | `#1E3A5F` | 最外框主色 |
| 外框金色点缀 | `#FFD700` | 外框四角/装饰条 |
| 主操作（接取） | `#3B82F6` | 蓝色按钮，选中页签同色 |
| 次操作 | `#A0A0A0` | 灰色按钮 |
| 正文 | `#FFFFFF` | 面板内标题/任务名 |
| 次要文字 | `#D0D0D0` | 编号、说明、日志 |
| 奖励文字 | `#FFE066` | 淡金，经验/奖励 |
| 完成 / 在线 | `#55FF55` | MC 风格绿 |
| 失败 / 危险 | `#FF5555` | 失败状态（预留） |
| 进行中 | `#55FFFF` | MC 风格青蓝 |
| 悬停行底 | `#3A5A7A` | 任务行悬停深蓝 |
| 选中·完成行底 | `#2E5E3E` | 任务行完成深绿 |

### 3.3 质感与细节语言

- 原版 MC 容器面板质感：面板灰 `#8B8B8B`，左上 1px 高光 `#C6C6C6`、右下 1px 阴影 `#555555`、最外 1px 黑色描边——即"斜切/錾刻"边。
- 最外框（整图 340×240 边缘）：4px 深蓝 `#1E3A5F` 边框 + 1px 金色 `#FFD700` 内衬线，四角各一个金色小方角点缀。
- 内部元素（栏、按钮、页签、行、开关）一律沿用 MC 斜切描边；**不做圆角、不做渐变、不做投影**。
- 任务行悬停 = 深蓝偏亮底 `#3A5A7A` + 悬停浮现完整信息 Tooltip。
- 禁忌：不使用办公/网页扁平风（浅灰底白卡片）、不使用紫金奢华风（与锻造台区分）、不出现真实文字。

## 五、公共组件设计规范

### 5.1 面板框架

- 整面板为深灰底，三块斜切描边灰板（`#8B8B8B` 底、左上 1px `#C6C6C6` 高光、右下 1px `#555555` 阴影、1px 黑色外描边），栏间 4px 露出深灰底色形成分隔。
- 整图最外框：4px 深蓝 `#1E3A5F` + 1px 金色 `#FFD700` 内衬线，四角金色小方角点缀。
- 顶栏深灰黑（`#3C3C3C`），标题居中留空（游戏内渲染白色标题）。
- 关闭按钮：顶栏右端 16×16，悬停时颜色变亮一档。

### 5.2 页签

- 造型：MC 斜切矩形，高 16px，宽 36px，相邻页签间距 2px。
- 选中态：蓝色底（`#3B82F6`）+ 白字，斜切描边（亮蓝 `#7AB8FF` / 暗蓝 `#1E4E7A`）。
- 未选中：灰板底（`#8B8B8B`）+ 浅灰字。
- 页签文字（全部 / 主线 / 支线 / 日常 / 活动）由游戏内渲染。

### 5.3 按钮

- 主操作（接取）：蓝色底（`#3B82F6`）白字，斜切描边（亮蓝 `#7AB8FF` / 暗蓝 `#1E4E7A`）+ 黑色外描边。
- 次操作（追踪 / 放弃）：灰底（`#A0A0A0`）白字；追踪开启时变绿底白字（代码覆盖）。
- 统一 56×14，1px 黑色描边，悬停叠加半透明白。

### 5.4 进度条

- 底槽：内凹深灰（`#3C3C3C`）180×6，左上暗边、右下亮边形成凹陷感。
- 填充：绿色（`#55FF55`），填充宽度 = 完成度比例 × 底槽宽度，由代码计算绘制。

### 5.5 开关

- 造型：26×11 MC 斜切矩形（外框黑色 1px）。
- 开：绿色底（`#55FF55`）+ 白色滑块右移；关：灰板底（`#8B8B8B`）+ 白色滑块左移。
- 滑块由代码绘制，不进贴图。

### 5.6 卡片 / 任务行

- 推荐卡：62×26 斜切灰板（`#6B6B6B` 底）+ 黑色描边，两行文字。
- 任务行：高 24px，左侧任务名 + 右侧状态文字，第二行左侧奖励（金）+ 右侧进度；
  - 悬停：深蓝底（`#3A5A7A`）+ 浮出完整信息 Tooltip；
  - 选中·完成：深绿底（`#2E5E3E`）；
  - 奇偶行交替底色（`#6B6B6B` / `#747474`）。

## 六、区域内容映射与渲染分工（核心）

### 6.1 设计稿 → 任务系统内容映射

> 设计稿是带示例数据的网页，以下映射保证「格式不变、只换内容」。

| 设计稿区域 | 原内容 | 任务系统替换内容 |
|------------|--------|------------------|
| 左面板标题 + 状态点 | 调度器状态 | 任务控制台 + 在线状态点 |
| 左面板统计字段 | 引擎/任务/账号/天数… | 进行中 / 已完成 / 失败 / 完成率 / 今日任务 |
| 最近日志（时间戳行） | 运行日志 | 任务日志（接取 / 完成 / 奖励） |
| 功能开关 | 日志/关注/私信开关 | 自动追踪 / 新任务提醒 |
| 中央横幅 + 头像 | 用户横幅 + 头像 | 任务分组横幅 + 物品图标 |
| 用户名 / 句柄 / 简介 | 用户信息 | 任务名 / 任务编号 / 描述 |
| 关注 / 关注者数据 | 社交数据 | 完成度 x/y + 进度条 |
| 消息 / 通知 / 正在关注按钮 | 社交操作 | 接取 / 追踪 / 放弃 |
| 内容分类页签 | 帖子/回复/转帖/媒体 | 全部 / 主线 / 支线 / 日常 / 活动 |
| 帖子列表 | 用户动态 | 任务列表（名称 + 状态 + 进度 + 奖励） |
| 搜索框 | 搜索 | 任务筛选 |
| 你可能喜欢 | 账号推荐 | 可接取推荐 |
| 有什么新鲜事 | 趋势话题 | 世界动态 / 事件 |

### 6.2 贴图 vs 代码分工表（金律）

| 元素 | 进贴图 | 游戏内渲染 | 说明 |
|------|:------:|:----------:|------|
| 页面底色 / 顶栏 / 三栏灰板 | ✅ | | 静态骨架 |
| 横幅深蓝底、卡片底、分隔线、斜切描边 | ✅ | | 静态骨架 |
| 按钮底形、页签底形、开关外框、进度条底槽 | ✅ | | 静态骨架 |
| **所有文字**（标题/名称/编号/统计/日志/按钮字/页签字） | ❌ | ✅ `font.drawString` | 数据与语言可变 |
| 物品图标（横幅） | ❌ | ✅ `renderItem` | 数据可变 |
| 进度条填充、状态点、开关滑块 | ❌ | ✅ `fill` | 随状态变化 |
| 悬停高亮、选中页签色块 | ❌ | ✅ `fill` | 交互态 |

**判断标准：内容一旦可能变化（数据、语言、数量、状态），就绝不能进贴图。**

## 九、实装衔接说明（供开发侧参考）

1. 选定图片后切片为 `assets/evolutionary_mod/textures/gui/task_screen.png`（340×240 或 2 倍放大后按 §4.2 坐标取用）。
2. 参考 `client/TaskScreen.java`：当前示例用 `fill()` 绘制全部骨架（路线 A，零贴图可直接运行）；后期将骨架替换为 `blit()` 贴图即可（路线 B），**文字/图标/进度渲染代码不动**。
3. 替换 `buildSampleData()` 为真实任务数据源（服务端任务进度经 `SavedData` / 网络包同步到客户端）。
4. 按键接入：`ClientHandlers` 注册 `OPEN_TASK_SCREEN`（建议 `U` 键），`ClientInputEvents` 中打开 `new TaskScreen()`。
5. 所有文本走 lang：`screen.evolutionary_mod.task`、`key.task.open`、`task.*` 等，双语同步（见 `修改同步索引表.md` §7）。
