# 修改同步索引表（数据/配置联动检查）

> 用途：修改下表左侧的「源文件」后，**必须按右侧「需同步检查」逐项核对**是否需要跟着改。
> 原则：**JSON 是主数据，Java 常量是回退**——改 JSON 时若不想让回退值"顶替"，要么同步改 Java 回退，要么接受回退只在新物品/缺条目时生效。

## 高频遗漏清单（自查口诀）

1. **改 JSON 忘了 Java 回退** → 新条目才走 JSON；老条目由 Java 回退顶替，改了个寂寞。
2. **改物品名忘了模型/纹理/lang** → 创造模式灰图标或原名。
3. **改槽位忘了 `AccessorySlot` 枚举** → 存储数组越界 / 槽位错乱。
4. **改引导书忘了 lang 双文件** → 分类/条目空白。
5. **改实体 ID 只改一处** → 不生成/不掉落，静默失败。
6. **新增套装只加 JSON** → 枚举/物品/lang 缺一，套装不生效。
