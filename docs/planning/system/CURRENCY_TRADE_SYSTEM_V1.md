## 一、核心设计理念

### 1.1 要解决的问题

当前成长几乎全靠「刷怪掉落 → 锻造强化」，玩家缺少：

| 痛点 | 说明 |
|------|------|
| 确定性 | 重锻石、高品阶碎片、属性精华完全看脸，缺"攒钱可得"的保底 |
| 目标感 | 缺少"攒一笔钱换想要的材料"的中期目标 |
| 回收出口 | 多余低品阶饰品、溢出材料无经济出口 |
| 惊喜感 | 缺少小额货币搏大奖励的随机体验 |
| 交易生态 | 货币与村民交易能把战斗收益转化为可控资源 |

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **货币是媒介，不是战力** | 货币无属性，只做兑换 |
| **特殊资源 = 保底通道** | 固定价定向兑换，解决"就差一种材料" |
| **随机资源 = 惊喜通道** | 低价搏高品阶，调节情绪曲线，不替代掉落主通道 |
| **商人分级 = 进度阶梯** | 低级商人练手、高级商人换高端货，构成成长目标 |
| **稀缺性放在"供给侧"** | 商人易得，商品限时限量——资源不泛滥、玩家不挫败 |
| **单级货币 + 券扩展** | 交易条目抽象"支付物"，未来可无缝加券（§9） |
| **不破坏掉落生态** | 随机兑换品阶池 ≤ 对应商人档；至臻仅掉落+升阶；不绕过 Boss 品阶池 |
| **JSON 管数值** | 掉率、价格、奖池、商人清单全部数据驱动 |

## 二、货币设计

### 2.1 货币本体

| 项 | 建议 |
|----|------|
| 物品 ID | `evolution_coin` |
| 中文名 / 英文名 | **进化铸币** / Evolution Coin |
| 可堆叠 | 64 |
| 是否消耗品 | 是（交易扣除 / 转职消耗） |
| 是否可合成/熔炼 | 否（防止绕过经济循环） |
| 外观 | 金色圆币 + 微光粒子，贴合模组紫金 UI 风格 |
| 掉落归属 | 独立判定通道（§3），不挤占饰品/材料掉率 |

### 2.2 为什么单级货币

- 玩家认知成本最低。
- 定价只需一张表，不用滚汇率。
- 高价值兑换直接用数量表达，无需第二种面额。
- 未来若需大额面值，走 §9 券通道。

## 三、货币获取

> 沿锻造材料双通道结构：**精英/Boss 走实体战利品表，原版怪/高难宝箱走 loot modifier 追加**，均独立判定，不吃 Looting。

### 3.1 掉落表（初值）

| 来源 | 掉率 | 数量 | 通道 |
|------|:---:|:---:|------|
| 原版普通怪（19 只） | 3% | 1～2 | GLM 追加 |
| 原版精英向（15 只） | 6% | 1～3 | GLM 追加 |
| 自定义精英·普通档（7 只） | 15% | 1～3 | 实体 loot |
| 自定义精英·高档（5 只） | 25% | 2～4 | 实体 loot |
| 顶级精英（2 只） | 60% | 3～6 | 实体 loot |
| Boss（凋灵/末影龙/坚守者） | 100% | 5～10 | 实体 loot |
| 高难宝箱 | 20% | 2～4 | GLM 追加 |
| 低阶宝箱 | ❌ | ❌ | —— |

### 3.2 幸运加成

- **所有来源均吃玩家幸运**（含原版普通怪/精英向）：实际掉率 = 基础值 + 幸运 × 1%（上限 100%）。
- 幸运取值：击杀取 `KILLER_ENTITY`、开箱取 `THIS_ENTITY`（与重锻石一致，见 `FORGE_SYSTEM_V1.md` §8.2.1 规则 2）。
- **不受 Looting 影响**（防止刷怪塔效率差）。

### 3.3 名单对齐说明

- 怪/宝箱名单复用 `FORGE_SYSTEM_V1.md` §8.2.1 的档位划分。
- 币掉落 **不写入** `drop_table.json`（那里只放饰品）。

## 四、交易村民设计与抉择

### 4.1 选型结论

- **否决方案 A（挂接原版职业村民）**：无法承载四级商人分级与随机资源、玩家识别度低、与绿宝石混流。
- **采用方案 B（新增独立职业村民「进化商人」）**：商品列表完全自主、四级分级可自由映射、随机资源可承载、货币独立流通、后续可扩展（券/亲密度/自定义 GUI）。

### 4.2 四级品阶商人

| 商人品阶 | 出售品阶 | 回收品阶 | 定位 |
|----------|----------|----------|------|
| **普通商人** | 残破 + 普通 | 残破~传说（至臻不收） | 新手启蒙 |
| **中级商人** | 优秀 | 同上 | 中期过渡 |
| **高级商人** | 史诗 | 同上 | 主力商人 |
| **终极商人** | 传说 | 同上 | 高端兑换 + 售刷怪蛋 |

**铁律：**

1. **至臻（MYTHIC）等级物品不售卖、不回收**——至臻保持"掉落 + 升阶"专属地位。
2. 商人**只卖本级品阶**（不含下级品阶）。
3. 商人**必须常驻**：死亡后通过再次转职/刷怪蛋补充。

### 4.3 商人升级与转职

**四级品阶构造：**

| 步骤 | 操作 | 消耗 |
|------|------|------|
| 获得普通商人 | 手持 **1 进化铸币** 右键**未就业村民** | 1 铸币 |
| 普通 → 中级 | 手持**中级升级徽章**右键普通商人 | 1 徽章 |
| 中级 → 高级 | 手持**高级升级徽章**右键中级商人 | 1 徽章 |
| 高级 → 终极 | 手持**终极徽章**右键高级商人 | 1 徽章 |
| **终极捷径** | 手持**终极徽章**右键**未转职村民** → **直接变终极商人**（跳过逐级） | 1 徽章 |

- 中级/高级徽章**不能**直变终极——必须逐级升级；终极徽章同时拥有"升级高级商人"与"直变"两种用法。

**升级通用规则：**

- 升级单向、不可回退（沉没成本）。
- 升级动作**不重置**该商人轮换商品（保留至下一次全局刷新，避免"升级=白嫖刷新"）。
- 转职/升级反馈：**成功 = 金色粒子 + 音效；失败 = 无任何反馈**。
- **交互判定优先级**（右键村民时按序判定）：① 手持对应**徽章** → 执行升级/直变；② 手持**铸币** + 目标为**未就业**村民 → 执行转职；③ 其余情况 → 兜底打开原版交易界面。

**商人死亡（D2.4）：**

- 不自动补偿；死亡后重新转职/使用刷怪蛋补充，需重新升级。
- **仅终极商人**出售「村民刷怪蛋」：**每次刷新窗口限购 1 个**，**兑换物 = 1× 终极徽章**（非铸币）。
- **刷怪蛋定位（价值说明）**：一键重获一个可转职的村民位——玩家拿到第 2 个终极徽章后，换 1 个普通村民（1 铸币转职）即拥有第二个终极商人，可兑换更多其它商品；对已有高级商人池的玩家有明确价值。

### 4.4 徽章合成配方

| 徽章 | 配方 | 合成结果 |
|------|------|----------|
| 中级升级徽章 | 中间 1× 进化铸币 + 外圈 8× 优秀品阶碎片 | 1× 中级徽章 |
| 高级升级徽章 | 中间 1× 中级徽章 + 上下左右 4× 史诗碎片 + 四角 4× 传说碎片 | 1× 高级徽章 |

- 中级/高级徽章 = **配方合成 + 掉落**双通道（碎片合成，无额外关键材料）。
- **配方无额外进度门槛**：始终可见、始终可合成，材料本身即天然门槛。
- **升级所需碎片（优秀/史诗/传说）只能通过精英/Boss 掉落获取**——商人不出售本档碎片之外的升级材料，这是刻意的难度设计（V1.5 确认：非缺陷，升级链路 = 打怪攒碎片 → 合成徽章）。
- **终极徽章不设合成配方**——仅 Boss 掉落。

### 4.5 徽章掉落表

> 铁律：同一来源内掉率严格递减 **中级 > 高级 > 终极**。

| 来源 | 中级徽章 | 高级徽章 | 终极徽章 |
|------|:---:|:---:|:---:|
| 自定义精英·普通档 | 5% | ❌ | ❌ |
| 自定义精英·高档 | 8% | 4% | ❌ |
| 顶级精英 | 10% | 6% | ❌ |
| **凋灵（wither）** | 45% | 30% | **25%** |
| **末影龙（ender_dragon）** | 45% | 30% | **25%** |
| **坚守者（warden）** | 20% | 12% | **5%** |
| 远古守卫者（elder_guardian） | ❌ | ❌ | ❌ |

**要点：**

- 终极徽章：凋灵 25% / 末影龙 25% / 坚守者 5%——顶级精英无终极徽章位（真 Boss 专属）。
- **坚守者全档压低**：因其可获得性高（深暗之域可反复触发），掉率显著低于凋灵/末影龙。
- 远古守卫者全档不掉，与锻造 Boss 池定位区分。
- **徽章掉落不吃幸运、不吃 Looting**（与铸币规则区分）。
- 数值全部进 `currency/badge_drops.json`，改配置不改逻辑。

### 4.6 实现要点

| 项 | 设计 |

## 五、交易体系分类

> 三类交易：**特殊资源（固定）/ 随机资源（随机）/ 出售回收（反向）**，按四级商人分档。

### 5.1 特殊资源兑换（保底通道 · 固定价）

**通用商品（四级商人均售）：**

| 商品 | 建议价 | 说明 |
|------|:---:|------|
| 饰品精华 | 2 | 强化燃料 |
| 属性精华（10 种） | 10 | 战略资源 |
| 引导书 | 5 | 可重复购买 |

**分档商品（碎片为常驻、重锻石为轮换）：**

| 商人 | 品阶碎片 | 建议价 | 重锻石 |
|------|----------|:---:|--------|
| 普通商人 | 残破 / 普通碎片 | 2 / 5 | 普通重锻石 |
| 中级商人 | 优秀碎片 | 12 | 普通重锻石 |
| 高级商人 | 史诗碎片 | 25 | 高级重锻石 + 锁定石 |
| 终极商人 | 传说碎片 | 50 | 高级重锻石 + 锁定石 |

- 至臻碎片不售卖。
- 库存上限见 **§6.3**。
- 定价铁律：「攒币可得 ≠ 刷怪高效」——掉落仍是主通道，货币只兜底。

### 5.2 随机资源兑换（惊喜通道 · 详见 §6）

| 商品 | 建议价 | 出售商人 | 产出 | 库存（每次刷新） |
|------|:---:|----------|------|:---:|
| 密封匣 4 档 | 5 / 15 / 40 / 120 | 按商人档 | 随机部位随机品阶（§6.1） | 5 / 10 / 15 / 25 |
| 随机材料包 | 8 | 四级均售 | 随机 1～3 件锻造材料（见权重表） | 2 / 4 / 6 / 10 按档 |
| 惊喜盒 | 25 | 中级及以上 | 材料/饰品/铸币返利混合池 | **5 各级一致** |

**惊喜盒定义：**

- 内容 = 随机锻造材料 / 随机白板饰品 / 小额铸币返利混合池。
- **货币返利上限 ≤ 12.5 铸币（盒价 × 50%）**，总期望 < 盒价（防必赚）。
- 产出遵守：禁至臻、禁 Boss 专属、产物白板无强化层。

**随机材料包产出权重表：**

> 每次开启随机掷 1～3 件，逐件按权重抽取；单件期望 ≈ 4 币，整包期望 ≈ 8 币（接近售价、不超不亏）。

| 产出 | 单件权重 | 备注 |
|------|:---:|------|
| 饰品精华 | 40 | 常见燃料 |

## 六、随机资源体系

### 6.1 密封匣（roll-on-open）

**原理**：商人出售「密封匣」物品；玩家右键开启时服务端才掷骰产出。原版交易界面无需改造，输出槽只放"匣"。

| 匣 | 建议价 | 品阶池 | 出售商人 |
|------|:---:|--------|----------|
| 普通饰品匣 | 5 | 残破 / 普通 | 普通商人 |
| 优秀饰品匣 | 15 | 普通 / 优秀 | 中级商人 |
| 史诗饰品匣 | 40 | 优秀 / 史诗 | 高级商人 |
| 传说饰品匣 | 120 | 史诗 / 传说 | 终极商人 |

**品阶池公式：本档位品阶 + 相邻低一档品阶**（普通商人本档 = 残破/普通），跨两档不入池；后续加档沿用。

**约束：**

1. 产出走饰品标准滚动逻辑（复用 `AccessoryRegistry` / `AccessoryDropTable` 品阶权重），部位随机。
2. 允许出现套装部件（权重可配）。
3. **禁止产出至臻物品；禁止 Boss 专属 / 白名单升阶物。**
4. 开匣产物为**白板饰品**（无强化层）——强化必须走锻造台。
5. 库存上限见 **§6.3**；每次全局刷新同步补满（§6.2）。
6. 保底机制见 **§6.4**。

### 6.2 全局定时刷新轮换商品

- **商品分类**：
  - 常驻商品：饰品精华、低阶碎片、普通重锻石、引导书（不参与刷新）
  - 轮换商品（可刷新）：属性精华、中高品阶碎片、高级/锁定重锻石、密封匣、惊喜盒、随机材料包
- **全局刷新时钟**：每隔固定现实时长，**所有商人轮换商品统一重新掷骰**（全局同步，非各自 restock）。
- 刷新时每位商人的轮换商品替换为随机 1～3 条（从该商人档位稀有池抽）；常驻商品不变。
- **刷新同步补满所有限购库存**（密封匣/重锻石/惊喜盒等）。
- **刷新频率初值：每现实 1 小时**（可配置）。
- **刷新提示（无广播）**：不向玩家全局广播；仅在商人交易界面内显示剩余时间（"下次补货 xx:xx"），玩家自行管理节奏。

**实现要点（NeoForge）：**

- 服务端 `SavedData` 记录下次刷新时间戳，跨重启持久。
- `ServerTickEvent` 检测时间点 → 对所有进化商人重掷轮换商品 + 补满限购库存。
- 交易界面顶部叠加倒计时渲染（复用原版 MerchantMenu 覆写绘制）。
- **刷新不依赖工作方块/原版 restock**：商人无 POI 也能正常补货——本系统全部库存与轮换由全局刷新时钟驱动，与原版 restock 完全解耦（V1.5 确认：无工作方块不影响刷新）。
- **轮换商品重写技术路径（实装注意）**：服务端遍历商人 `merchant.getOffers()` 清空重填/只替换轮换条目 + `setOffers`；**需处理客户端同步**（打开交易界面的客户端看到的是缓存 offers）——实装时验证是否需要包一层同步信号或复用 `MerchantTradesUpdatedS2C` 通道。该点需 spike（详见 §12.2）。

### 6.3 购买上限：原版商人库存

- 上限完全依赖**原版商人库存 `max_uses` 字段**（数值上限），每次**全局刷新时钟重置库存**（无玩家每日配额；不使用原版 restock 机制）。
- **每次全局刷新补满所有轮换商品库存**。
- 权威数值表：

| 商品类别 | 库存上限（每次刷新窗口） |
|----------|:---:|
| 常驻商品（精华/低阶碎片） | 高库存（12~64，不限流） |
| 普通重锻石（普通 / 中级商人） | **5 / 15** |
| 高级重锻石（高级 / 终极商人） | **10 / 25** |
| 锁定重锻石（高级 / 终极商人） | **1 / 3** |
| 密封匣（普通/优秀/史诗/传说） | **5 / 10 / 15 / 25** |
| 随机材料包（按商人档） | **2 / 4 / 6 / 10** |
| 惊喜盒 | **5（各级一致）** |
| 轮换稀缺商品（高品阶碎片/属性精华） | **待定**（建议初值 1~3；后续加新商品时一并定） |
| 村民刷怪蛋（终极商人） | **1 个/刷新窗口** |

### 6.4 保底

- **密封匣 90 次保底**：每档匣子按玩家累计"未出本档最高品阶"的连续开启次数 `n`；`n ≤ 80` 正常权重滚动；**`n ≥ 81` 起本档最高品阶概率 = `n + 10%`（81→91% … 90→100%）**；出货后 `n` 归零。本档最高品阶 = 该匣品阶池内最高档（普通匣=普通、优秀匣=优秀、史诗匣=史诗、传说匣=传说）。
- **计数载体（V1.5 定稿）**：走**玩家实体附件（NeoForge `AttachmentType`）**，**仅保证同一个存档内一致**（存读档/重进世界时保留），**不做跨存档世界间传递**（每个存档独立计数，避免跨档累积作弊）。
- 惊喜盒货币返利 ≤ 盒价 × 50%，总期望 < 盒价。
- 远期"保底券"走 §9 券通道。

## 七、出售回收

### 7.1 品阶档位回收价格表

**规则：每种品阶的物品回收价按「商人档位」列出；物价以"同级商人"为最高点，向两侧跨档等差递减（每跨一档减固定步长），最低不低于 1 铸币。**

| 物品品阶 | 普通商人 | 中级商人 | 高级商人 | 终极商人 | 步长 |
|----------|:---:|:---:|:---:|:---:|:---:|
| 残破 | 3 | 2 | 1 | 1 | -1 |
| 普通 | 6 | 4 | 2 | 1 | -2 |
| 优秀 | 11 | 15 | 11 | 7 | -4 |
| 史诗 | 14 | 22 | 30 | 22 | -8 |
| 传说 | 5 | 30 | 55 | 80 | -25 |
| 至臻 | ❌ | ❌ | ❌ | ❌ | 不收 |

**价格生成逻辑：**

- **同级商人 = 最高价**（对角线：残破→普通、普通→普通、优秀→中级、史诗→高级、传说→终极）。
- 从同级档往**两侧**各跨一档，价格等差递减一个步长（残破 1 / 普通 2 / 优秀 4 / 史诗 8 / 传说 25）。
- **最低价下限 = 1 铸币**。

**经济安全规则：**

1. 强化过的饰品禁止出售——防止把锻造投入换算成货币。
2. 跨级回收天然压价，"卖废品攒钱"转化率低于刷怪。
3. 回收条目走原版 `max_uses` 字段 + 全局刷新重置限制批量出货。

## 八、与现有系统的边界

```
掉落（已有）        锻造（已有）        货币交易（新增）
─────────          ──────────        ──────────────
GLM → 饰品成品       强化/重锻/粉碎     币掉落（独立判定）
词条滚动             材料掉落           商人：特殊/随机/出售
```

**禁止：**

- 货币交易产出**带强化层**的物品（兑换出白板，强化走锻造台）。
- 随机兑换绕过品阶池（例：普通匣出史诗）。
- 用货币直接购买"升阶"（升阶仅白名单，见 `FORGE_SYSTEM_V1.md` §7）。
- 至臻等级物品进入任何交易渠道（售卖/回收/随机池）。
- 币掉落写入 `drop_table.json` / 污染原版战利品表文件。

## 九、扩展预留：特殊券

> D1：**单级货币不动，券作为"资格/附加"层，未来无缝叠加。**

### 9.1 预留的设计抽象

1. **支付物可配置**：交易条目"支付"字段目前固定 `evolution_coin`，预留可扩展为「货币 + 券」组合（原版交易天然支持双输入槽 `buy` + `buyB`）。
2. **券 = 资格条件**：特殊券兑换 = 商品支付要求"货币 + 特定券"，同一套商人 UI 与交易结构直接承载。
3. **券 = 加成/保底**：附带券可提高随机池命中率或解锁限定商品（§6.4）。
4. **券 = 商人/徽章解锁**：未来可让徽章、刷怪蛋等通过券触发。

### 9.2 V1 阶段落点

- 交易 JSON schema 预留 `pay_requirements` 扩展字段。
- **实装不做**任何券物品、不引入券逻辑，保证"将来加物料不改结构"。
- 后续修订时新开 `SPECIAL_VOUCHER_SYSTEM` 策划案细化券的获取与用途。

## 策划案总结

| 模块 | 一句话 |
|------|--------|
| 货币 | 单级「进化铸币」，纯兑换媒介，独立判定掉落，全部来源吃幸运 |
| 获取 | 精英/Boss/宝箱掉落 + 出售多余饰品/材料回收 |
| 商人 | 独立职业「进化商人」，四级品阶分档售卖，1 铸币转职未就业村民 |
| 升级 | 徽章制：中级/高级徽章配方+掉落双通道；终极徽章仅 Boss（凋灵/末影龙 25%、坚守者 5%） |
| 特殊资源 | 固定价定向兑换全系列锻造材料（保底通道，按商人档位开放） |
| 随机资源 | 密封匣 4 档 + 随机材料包 + 惊喜盒（允许套装部件、禁至臻、限购、90 次保底） |
| 供给控制 | 全局定时刷新（每现实 1 小时）+ 原版库存 `max_uses` 限购 |
| 出售回收 | 档位价格表（同级最高、跨级等差递减、下限 1）；至臻不售不回收；未强化可售 |
| 扩展预留 | 券作为"资格/附加"层，交易 schema 预留 `pay_requirements` |
