## 一、核心设计理念

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| **适度限制** | 初始上限较低，让玩家明显感受到负重存在 |
| **渐进解锁** | 通过游戏进程逐步提升负重上限 |
| **沉浸体验** | 负重系统融入游戏玩法，增加策略深度 |
| **可扩展性** | 预留扩展空间，支持后续自定义物品 |

### 1.2 核心机制

```
玩家总负重上限 = 基础上限 + 等级加成 + 装备加成（背包）
```

### 3.2 堆叠重量计算（线性模式）

```
堆叠重量 = 基础重量 × 堆叠数量
```

**示例**：
- 64个石头 = 0.3 × 64 = 19.2
- 64个铁锭 = 0.5 × 64 = 32
- 64个钻石 = 1.0 × 64 = 64

## 四、惩罚机制

### 4.1 速度惩罚

```
实际速度 = 基础速度 × (1 - 超载比例 × 惩罚倍率)
```

| 当前负重 | 超载比例 | 速度惩罚 | 实际速度 |
|----------|----------|----------|----------|
| ≤安全阈值 | 0% | 0% | 100% |
| 安全~警戒 | 1%-25% | 0.5%-12.5% | 99.5%-87.5% |
| 警戒~上限 | 26%-40% | 13%-20% | 87%-80% |
| 超过上限 | >40% | 20% | 80%（最低速度） |

### 4.2 饱食惩罚

| 状态 | 饱食消耗倍率 | 说明 |
|------|--------------|------|
| 正常 | 1.0x | 无惩罚 |
| 负重 | 1.2x | 轻微加速 |
| 超重 | 1.5x | 明显加速 |
| 超载 | 2.0x | 严重加速 |

### 4.3 负重状态分级

| 状态 | 条件 | 视觉提示 | 效果 |
|------|------|----------|------|
| NORMAL（正常） | <60% | 绿色 | 无惩罚 |
| HEAVY（负重） | 60%-85% | 黄色 | 速度-5%~12% |
| OVERWEIGHT（超重） | 85%-100% | 橙色 | 速度-13%~20% + 饱食1.5x |
| OVERLOADED（超载） | ≥100% | 红色 | 速度-20% + 饱食2.0x |

## 五、游戏体验测试


## 八、策划案总结

### 8.1 核心改动

| 维度 | 原方案(V3) | 新方案(V4.1) |
|------|------------|--------------|
| 基础上限 | 800 | **120** |
| 解锁方式 | 固定 | **渐进解锁** |
| 物品重量 | 低(0.05-0.5) | **适中(0.2-5.0)** |
| 饰品加成 | 有 | **已移除** |
| 游戏影响 | 极小 | **明显但不阻碍** |

### 8.2 设计亮点

1. **渐进式成长**：通过等级、装备、成就逐步提升上限，符合游戏进度
2. **适度挑战**：初始120上限让玩家需要策略性管理背包
3. **策略深度**：玩家需要权衡携带物品的价值与重量
4. **扩展性**：预留足够空间支持后续自定义物品

### 8.3 当前上限计算公式

```
总上限 = 120(基础) + 等级×2 + 背包加成 + 成就加成
```
