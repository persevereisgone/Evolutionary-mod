# Minecraft 物品重量系统设计文档

## 文档说明

本文档详细列出了 Minecraft 原版所有可拾取物品的重量值，用于负重系统。

**重量单位**：1 重量单位 ≈ 1 千克（kg）

**设计原则**：
- 贴近现实重量，但适当调整以保证游戏体验
- 堆叠物品按单个重量计算
- 工具和武器考虑材质和尺寸
- 护甲考虑材质和覆盖面积
