## 文档目录（Docs）

这里存放可长期维护的文档，分为**策划案**、**玩家版**与**开发者版**三套。

---

## 策划案文档 (planning/)

存放游戏设计策划案，包含已实装和待实装的方案。

```
planning/
├── system/          # 系统策划
│   ├── WEIGHT_SYSTEM_V4.md       # 负重系统策划案（已实装）
│   ├── FORGE_SYSTEM_V1.md        # 锻造台：强化 / 重锻 / 粉碎 / 特例升阶（待实装）
│   └── GUIDE_SYSTEM.md           # 自研指南 UI（搁置；游戏内改用 Patchouli）
├── balance/         # 平衡性策划
│   └── ITEM_WEIGHTS.md           # 物品重量参考
└── config/          # 配置示例
    └── WEIGHT_CONFIG_EXAMPLE.toml # 负重系统配置示例
```

### 策划案状态说明

| 状态 | 说明 |
|------|------|
| ⚠️ 搁置 | 暂时搁置，可直接按策划案实装 |
| 🚧 开发中 | 正在开发中 |
| ✅ 已实装 | 已完成开发并实装 |

### 策划案命名规范

- 格式：`{功能名}_SYSTEM_V{版本号}.md`
- 示例：`WEIGHT_SYSTEM_V4.md`
- 版本号从V1开始，每次重大修订递增

## 开发者文档 (dev/)

- `dev/开发者指南-精简版.md`：给作者/维护者看的维护手册（新增内容要改哪些文件、如何验证、常见坑）
- `dev/Patchouli引导书开发指南.md`：游戏内《进化指南》的 JSON/lang 位置、修改与扩展步骤

---

## 维护约定（推荐）

- **一份事实一处维护**：比如快捷键、指令、槽位数量等信息尽量只在一处写清，再在其他文档引用它，避免日后改动漏改。
- **用"可追加列表"而不是"写死段落"**：例如"精英怪列表""套装列表""词条列表"优先用表格/清单，后续只需要追加行。
- **版本提示**：每次大改玩法，在文档顶部加一行"适用版本/变更点"，方便玩家对照。
- **策划案搁置规范**：策划案搁置时，需在文档末尾添加"搁置说明与实装注意事项"章节，包含实装检查清单、依赖关系、关键代码片段等内容。
