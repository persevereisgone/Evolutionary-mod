 物品图片 AI 提示词【中文版】（锻造系统 v1.3 + 货币交易体系 v1.4）
 覆盖：3 类型精华 + 10 属性精华 + 6 品阶碎片 + 3 重锻石 + 11 货币交易物品 = 33 件
 适用：即梦 / 可灵 / 通义万相 等中文生图工具
====================================================

【系列设计思路 · v1.4】
- 33 件物品 = 6 个家族，每件独立设计，造型互不雷同：
  * 类型精华（3）—— 发光晶石质感，3 种独立剪影
  * 属性精华（10）—— 属性实体结晶，10 种独立剪影
  * 品阶碎片（6）—— 残片晶体家族，稀有度色阶递进，6 种残片剪影
  * 重锻石（3）—— 石头质感家族，3 种独立造型
  * 货币（1）—— 紫金圆币，全模组经济媒介
  * 徽章（3）—— 圆形吊耳徽章同族，颜色 + 浮雕递进
  * 密封匣（4）—— 方形封印匣同族，颜色 + 饰纹递进
  * 随机包盒（2）+ 刷怪蛋（1）—— 布袋 / 礼盒 / 蛋形
- 统一语言只保留四点：全部居中构图、全部透明背景、
  全部体素方块像素风格、全部无文字。
- 颜色铺满整个色环；同一家族内颜色两两拉开，跨家族若颜色接近，
  靠「材质 + 剪影」强区分（碎片=残片，精华=宝石，石头=原石，
  匣子=方盒，徽章=圆徽，袋子=布袋）。
- 成图规格：512x512 即可，之后缩到 Minecraft 16x16；
  背景必须完全透明（游戏贴图不能有底色/底板）、物品居中、无文字。

 八、使用建议
====================================================
1. 所有图标统一使用「完全透明背景」生成，严禁出现任何底色/底板，
   否则进游戏后物品框会被黑底遮挡，拿在手上也是黑色方块。
   若生图工具不支持透明 PNG，请生成后在图片处理软件中一键抠掉纯色背景。
2. 缩到 16x16 后若轮廓看不清，优先保持「颜色 + 剪影」，不要强塞细节，
   靠不同的外形剪影区分（这正是每件独立造型的意义）。
3. 生成文件命名直接对齐注册名（model JSON 引用）：
   锻造系：accessory_essence / weapon_essence / armor_essence
   attribute_essence_life / attack / armor / speed / luck / regen / penetration /
   crit_chance / crit_damage / reduction   （共 10 个，.png）
   rank_shard_broken / normal / excellent / epic / legendary / mythic （共 6 个，.png）
   reroll_stone / reroll_stone_advanced / reroll_stone_lock   （共 3 个，.png）
   货币系：evolution_coin / badge_intermediate / badge_advanced / badge_ultimate /
   pouch_common / pouch_excellent / pouch_epic / pouch_legendary /
   material_pouch / surprise_box / villager_spawn_egg   （共 11 个，.png）
