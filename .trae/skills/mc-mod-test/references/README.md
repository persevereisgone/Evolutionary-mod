# MC Mod Test Skill 参考文档

## 快速开始

### 触发方式

当你想测试模组时，只需说：

- "测试一下"
- "运行测试"
- "测试新功能"
- "检查代码bug"
- "验证构建"

### Skill会自动执行

1. **代码静态检查** - 检查关键文件和代码模式
2. **构建测试** - 执行 `gradlew build`
3. **运行测试** - 提供运行客户端的指引
4. **生成报告** - 输出结构化测试报告

## 测试报告示例

测试完成后会生成报告，保存在：

```
docs/testing/TEST_REPORT_<功能名>_<日期>.md
```

报告包含：
- 测试结果总览
- 详细测试结果
- 发现的问题清单
- 修复建议

---

## 常见问题

### Q: 如何只运行特定测试？
A: 告诉我要测试的具体功能，例如："只测试负重系统"

### Q: 能否自动修复发现的问题？
A: 目前需要你确认后手动修复，未来可扩展自动化修复功能

### Q: 测试失败怎么办？
A: 查看报告中的问题清单和建议修复方案，按优先级修复后重新测试
